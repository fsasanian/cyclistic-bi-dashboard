## Key Metrics
- Trip Count
- Average Trip Minutes
- Borough Usage
- Trips by Zip Code
- Trips by User Type

## Key Insights
- Subscribers generated significantly more trips than customers.
- Manhattan showed the highest bike usage.
- Trip duration differed between user types.
- Geographic patterns highlighted high-demand zip codes.
- ## Project Summary

This project analyzes Cyclistic bike trip data to understand rider behavior, trip duration patterns, and geographic usage trends across New York City.

Using SQL and BigQuery, trip, weather, and geographic datasets were combined to create an interactive Tableau dashboard. The dashboard highlights key business metrics such as trip counts, average trip duration, borough usage, user type behavior, and zip code activity.

The visualizations were designed to help stakeholders quickly identify:
- Differences between subscribers and customers
- High-demand geographic areas
- Areas with the highest bike activity
- User travel behavior patterns

The dashboard also includes interactive filtering using Tableau actions, allowing users to explore geographic trends dynamically.
